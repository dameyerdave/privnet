Good to know

DNS rebinding protection, renewal, rate limits
  • DNS rebinding protection: some home routers and resolvers (FRITZ!Box, pfSense, OPNsense, Pi-hole/dnsmasq with stop-dns-rebind) drop public answers that contain private IPs. If names don't resolve at home, add an exception for {{.Zone}}. With dnsmasq, that's rebind-domain-ok=/{{.Zone}}/.
  • Renewal: every recipe renews automatically, as long as the same credentials keep working. Rotating the API key means updating your clients.
  • Rate limits: all namespaces share Let's Encrypt's limit for {{.Zone}}'s registered domain. One wildcard per namespace is the friendly choice, and renewals don't count.
