  1. Install WireGuard

    Works on any recent distribution with kernel 5.6 or newer, including Raspberry Pi OS.

    # Debian / Ubuntu / Raspberry Pi OS
sudo apt update && sudo apt install -y wireguard-tools

# Fedora / RHEL
sudo dnf install -y wireguard-tools

# Arch
sudo pacman -S --needed wireguard-tools

  2. Create /etc/wireguard/{{$cb.ConfFile}}

    {{if .Join}}

    Download the config directly with this one-time-link command:

    sudo install -d -m 700 /etc/wireguard
sudo curl -fsSL -o /etc/wireguard/{{$cb.ConfFile}} '{{.AbsConfigURL}}'
sudo chmod 600 /etc/wireguard/{{$cb.ConfFile}}

    Or paste it manually:

    {{end}} 
    sudo install -d -m 700 /etc/wireguard
sudo tee /etc/wireguard/{{$cb.ConfFile}} > /dev/null <<'EOF'
{{$cb.Config}}EOF
sudo chmod 600 /etc/wireguard/{{$cb.ConfFile}}

  3. Connect, and reconnect at every boot

    sudo systemctl enable --now wg-quick@{{$cb.Iface}}

    To connect once without autostart, run sudo wg-quick up {{$cb.Iface}} instead (and sudo wg-quick down {{$cb.Iface}} to disconnect).

  4. Check the tunnel

    sudo wg show {{$cb.Iface}}
ip addr show {{$cb.Iface}}    # should list inet {{$cb.Device.IP}}/32
    {{template "cb-expect" .}}

  5. Reach the other devices

    {{template "cb-peers-unix" .}}

  6. Optional: use names instead of IPs

    sudo tee -a /etc/hosts > /dev/null <<'EOF'
{{$cb.HostsSnippet}}EOF

    After this, ping {{$cb.FQDN}} works. If devices are added later, refresh this page for the updated list.

  7. Disconnect or uninstall

    sudo systemctl disable --now wg-quick@{{$cb.Iface}}
sudo rm /etc/wireguard/{{$cb.ConfFile}}

  1. Install WireGuard

    Download the official installer from https://download.wireguard.com/windows-client/wireguard-installer.exe, or in PowerShell:

    winget install --id WireGuard.WireGuard -e

  2. Get the configuration file

    Download {{$cb.ConfFile}} It's saved to %USERPROFILE%\Downloads\{{$cb.ConfFile}}.

  3. Import and activate

    Open WireGuard → Import tunnel(s) from file → choose {{$cb.ConfFile}} → Activate. The tunnel is called {{$cb.Iface}}.

    Prefer an always-on background service that starts at boot? In an Administrator PowerShell:

    & "C:\Program Files\WireGuard\wireguard.exe" /installtunnelservice "$env:USERPROFILE\Downloads\{{$cb.ConfFile}}"

    Remove it again with & "C:\Program Files\WireGuard\wireguard.exe" /uninstalltunnelservice {{$cb.Iface}}

  4. Let the other devices ping this PC

    Windows Firewall blocks incoming ping by default. Allow it from your private network only (Administrator PowerShell):

    New-NetFirewallRule -DisplayName "privnet {{$cb.Iface}} ping" -Direction Inbound -Protocol ICMPv4 -IcmpType 8 -RemoteAddress {{$cb.Network.Subnet}} -Action Allow

  5. Check the tunnel

    In the WireGuard window, Latest handshake should show a recent time. {{template "cb-expect" .}}

    # gateway (privnet hub)
ping -n 3 {{$cb.Plan.Gateway}}
{{range $cb.Others}}# {{.Name}} ({{.FQDN}})
ping -n 3 {{.IP}}
{{end}}

  6. Optional: names instead of IPs

    In an Administrator PowerShell:

    Add-Content -Path "$env:SystemRoot\System32\drivers\etc\hosts" -Value @"
{{$cb.HostsSnippet}}"@
ipconfig /flushdns

  1. Install the app

    Install WireGuard by WireGuard Development Team from the App Store.

  2. Add the tunnel

    {{if $cb.HasKey}}

    Scanning from a computer screen: open WireGuard → + → Create from QR code → point the camera at the QR code on this page.

    Viewing this page on the iPhone: tap Download {{$cb.ConfFile}} → Share → WireGuard.

    {{else}}

    Open WireGuard → + → Create from scratch, then enter the values from “At a glance”, using your own private key.

    {{end}}

  3. Name it and allow VPN

    When asked for a name, enter {{$cb.Iface}}. Tap Allow to add the VPN configuration and confirm with Face ID or your passcode.

  4. Switch it on

    Toggle {{$cb.Iface}} on. Tap the tunnel to see Latest handshake. {{template "cb-expect" .}}

    Only traffic to {{$cb.Network.Subnet}} uses the tunnel. Normal browsing keeps your usual connection.

  5. Stay connected

    Tap the tunnel → Edit → On-Demand Activation → enable Cellular and Wi-Fi.

  6. Test it

    From another device in the network, run ping {{$cb.Device.IP}}. From this iPhone, open a service on a peer, for example http://{{if $cb.Others}}{{(index $cb.Others 0).IP}}{{else}}{{$cb.Plan.Gateway}}{{end}}.

  1. Install the app

    Install WireGuard (com.wireguard.android) from Google Play or F-Droid.

  2. Add the tunnel

    {{if $cb.HasKey}}

    Scanning from a computer screen: open WireGuard → + → Scan from QR code → point the camera at the QR code on this page.

    Viewing this page on the phone: tap Download {{$cb.ConfFile}}, then in WireGuard tap + → Import from file or archive → select {{$cb.ConfFile}} from Downloads.

    {{else}}

    Open WireGuard → + → Create from scratch, then enter the values from “At a glance”, using your own private key.

    {{end}}

  3. Name it and connect

    Name the tunnel {{$cb.Iface}}, flip its switch on and accept Android's Connection request dialog.

    {{template "cb-expect" .}}

  4. Stay connected

    Android Settings → Network & internet → VPN → gear next to WireGuard → enable Always-on VPN. Leave “Block connections without VPN” off, because privnet only carries traffic for {{$cb.Network.Subnet}}.

  5. Test it

    From another device in the network, run ping {{$cb.Device.IP}}. Tap the tunnel in the app to watch the transfer counters go up.
