How it works

  1. Names resolve to private IPs

    192-168-1-10.yourname.{{.Zone}} resolves to 192.168.1.10 from anywhere, with no setup. You can also add your own names, like nas.yourname.{{.Zone}}. Only private ranges are ever answered.

  2. Only you can prove ownership

    Each namespace has its own API credentials. Your ACME client uses them to publish the DNS-01 challenge, so nobody else can get a certificate for your names.

  3. One wildcard certificate covers everything

    Request *.yourname.{{.Zone}} once and it covers every IP and device name in the namespace. Ready-made recipes cover lego, certbot, acme.sh, Traefik, cert-manager and Caddy.
